---

## Exam Overview

The Certified Blockchain Developer – Ethereum (CBDE) certification validates practical knowledge and skills for planning, developing, testing, and deploying applications and smart contracts on the Ethereum blockchain.

- **Exam Format**: Online, multiple-choice examination with a performance-based evaluation
- **Target Audience**: Software engineers, programmers, developers, and application architects
- **Prerequisites**: No formal prerequisites are listed in the official certification information

---

## Core Exam Domains & Knowledge Areas

The following numbered areas organize the skills and capabilities published by Blockchain Training Alliance. They are study-guide groupings, not separately named or weighted official exam domains.

### 1. Ethereum Application Development

- Plan and prepare production-ready applications for the Ethereum blockchain.
- Understand Ethereum capabilities, constraints, and development environments.
- Use essential tooling and systems across the Ethereum ecosystem.

### 2. Solidity & Secure Smart Contracts

- Write, read, and compile Solidity smart contracts.
- Apply secure smart-contract development practices.
- Understand contract behavior and development considerations.

### 3. Smart Contract Testing & Deployment

- Unit test smart contracts and validate expected behavior.
- Deploy smart contracts to Ethereum test networks and live networks.
- Run an Ethereum node in a development environment.

### 4. Web3 Integration & Ethereum Gas

- Implement application interactions with Ethereum using web3.js.
- Understand Ethereum fees and calculate gas costs.
- Use Ethereum development tools to support application integration and deployment.
